# QuickQuiz ⚡

**Author**: Mahmoud Abdulhaq  
**Date**: 11/29/11

QuickQuiz is a fast-paced, interactive trivia and quiz game built for players of all levels. Test your knowledge, climb streaks, unlock achievements, or create and share custom quizzes.

## Features

- **Multiple Game Modes**:
  - **Classic**: 10 questions at your own pace with a generous question timer.
  - **Blitz**: Rapid-fire 15-second countdown per question with combo streak multipliers.
  - **Endless Survival**: See how far you can go with 3 lives.
  - **Daily Challenge**: Fresh curated quiz challenge with daily streak counter.
- **10 Rich Categories**:
  - Science & Nature
  - Technology & Coding
  - History & Civilizations
  - Geography & World
  - Pop Culture & Movies
  - Video Games
  - Literature & Arts
  - Sports & Records
  - Brain Teasers & Riddles
  - General Knowledge
- **Lifelines**: 50/50, Hint, and Skip options to save your streak.
- **Audio & Visual Feedback**: Synthesized Web Audio sound effects, celebration confetti, and clean animations.
- **Custom Quiz Builder**: Build custom trivia packs with custom options, explanations, and timers, or export/import them as JSON.
- **Stats & Achievements**: Track accuracy, high scores, streaks, and unlock unique accomplishment badges stored in LocalStorage.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
